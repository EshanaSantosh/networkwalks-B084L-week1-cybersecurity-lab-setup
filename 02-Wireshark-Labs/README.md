## 📌 About the Project

This repository documents my hands-on Wireshark lab work completed as part of the Networkwalks Cybersecurity Program.

The labs provided practical experience in inspecting network packets, identifying protocols, analyzing authentication traffic, and understanding communication over a network.

## 🧪 Practical Labs

### 🔎 01 — Network Traffic Analysis

- Explored captured network traffic in Wireshark.
- Used Protocol Hierarchy and packet statistics.
- Identified relevant protocols and IP addresses.
- Practiced examining packets using display filters.

### 🔑 02 — FTP Authentication Analysis

- Identified the FTP server and client IP addresses.
- Examined login attempts and repeated username patterns.
- Interpreted FTP response codes, including `530` and `230`.
- Investigated authentication traffic and brute-force attack indicators.
- Learned why encrypted protocols are important for protecting credentials.

### 📞 03 — SIP & RTP Voice Traffic Analysis

- Identified SIP signaling used to establish a call.
- Examined the SIP INVITE and caller extension information.
- Explored RTP packets carrying voice traffic.
- Investigated codec information and call-related network traffic.
- Learned how Secure Real-time Transport Protocol (SRTP) helps protect voice communication.
